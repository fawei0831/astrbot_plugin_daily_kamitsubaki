今日神椿 · 网页导出

读取你已打开的投稿页，导出歌名、BV号、封面地址。不会下载歌曲或读取密码、Cookie，也不会自动翻页。

  1. 按 Ctrl+Shift+B 显示 Chrome 书签栏，把下方按钮拖到书签栏。不要直接点它。

    导出神椿当前页

  2. 打开歌手的投稿页：花谱 · 春猿火 · ヰ世界情緒。等待视频显示，向下滚动到页底，使封面加载。
  3. 点击刚才保存的书签，下载当前页 JSON 清单。下一页由你手动翻页，再点书签。重复导出同一页也可以，导入时会去重。
  4. 回到工具文件夹，双击导入浏览器清单.cmd，选择刚才下载的 JSON 文件，可多选。电脑需已安装 Python；当前这台电脑已具备。

结果保存在 .catalog-work/review.json，这是待核对清单，不会自动修改服务器正式曲库。视频数不等于歌曲数，预告、演唱会、现场版仍需核对。

首版只接受已核对的三个账号。其他歌手应先核对官方账号，再加入 tools/channels.json。工具本身不消耗 AI token；请求助手检查结果或改代码才会产生对话用量。若网页提示验证，请自行按网站正常流程处理。
