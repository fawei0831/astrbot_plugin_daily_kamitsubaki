# 今日神椿

## 管理页面（1.1.0）

从AstrBot插件列表的今日神椿卡片打开“管理页面”（pages/manage）。可查看正式曲库和待补充资料、搜索歌手/歌名、启停歌曲、运行/停止服务器补曲任务、查看实时日志和风控暂停时间、审核候选并加入正式曲库。

新增歌曲和启停状态保存在服务器plugin_data/astrbot_plugin_daily_kamitsubaki/catalog.json，升级插件不会覆盖；七天历史仍使用原history.db。补曲任务在服务器运行，不调用AI，最多10次请求、至少8秒间隔，风控暂停至少24小时且无法从页面强行重置。候选未经审核不入库。

独立 AstrBot 插件，群聊 @Bot 今日神椿，私聊发送 今日神椿。

曲库包含神椿观测站的早期21首及用户从B站公开投稿页导出的非现场歌曲。当前正式快照1832首，优先官号、无官号对应候选时用神椿音乐站补缺。新增条目的歌名和演唱者基于标题整理，未提供发行日的显示“未知”，来源明确标为B站公开投稿，不冒称来自百科。封面来自对应B站视频并缓存到本地。每次一首，先随机有可抽歌曲的歌手，再随机歌曲。各平台、各群和每位私聊用户独立记录；成功发送后连续168小时不重复。同一歌手同一首歌的现场版和Remix共用冷却。

资料来源：https://kamitsubaki.wiki/zh/ ，https://github.com/LinkTh1rsty/kamitsubaki-wiki-site 。资料文字遵循原站CC BY-NC-SA 4.0，音视频和封面归原权利人。未复制歌词。

catalog.json是正式曲库快照；升级已有部署时，持久化catalog.json不会自动覆盖，需备份后显式合并新曲库。封面优先读取已导出的hdslb图片链接，不必重复查询视频信息接口。封面或平台图片发送失败时降级文字。

## 批量扩充曲库

见 [批量整理工具说明](tools/README.md)。工具附带1,050首歌曲的离线资料索引，可低频采集公开B站投稿、缓存并断点续跑，遇到风控停止。所有候选都需核对后才能导出，不会自动改动正式曲库。不调用AI，无需逐首打开网页。

## 安装与更新
在 AstrBot 插件页面选择从链接安装，填写 https://github.com/fawei0831/astrbot_plugin_daily_kamitsubaki 。后续在插件页面检查更新。

首版21首已扩展至1832首（1514官号、318搬运补缺），保留原历史数据库。已剔除标题标注的现场内容及额外发现的3条游戏/动画PV，并修正Op编号标题与重复译名；历史/同集团及归属未确定的分组未纳入本次扩容。未逐视频观看，标题与内容仍可能有漏检。当前没有自动同步任务。

## 封面缓存空间
每个插件生成的BV封面缓存上限为50 MiB（52,428,800字节）。启动与新增封面后清理最久未使用的生成图片，使用已有封面会更新最近使用时间。仅清理covers目录中BV命名的图片，不清理数据库、推荐记录或其他文件。被清理的封面下次按需获取；不下载音频或视频。两个插件合计最多约100 MiB生成封面缓存。
